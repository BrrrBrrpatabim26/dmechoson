# Experience

> Accumulated UI design experience across this project's
> `/fullstack.improve-design` runs. The skill appends a new entry after
> each page that classifies its evaluation findings as "Experience"
> (rather than a confirmed "Anti-UI Pattern").

## Format

Each entry is dated and describes **what the AI learned** about this
project's UI specifically. Anti-patterns that recur in many projects
go to `anti-ui-patterns.md` instead.

```markdown
## YYYY-MM-DD — <page_id> (loop vN)

**What I tried**:
…

**What worked**:
…

**What didn't**:
…

**Next time**:
…
```

## How to use

The skill loads this file into the **Page Context** for every page.
Over time it becomes the project's most valuable UI asset: a curated
list of what *actually works* for this product, this audience, this
stack.
