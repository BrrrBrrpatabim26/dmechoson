# Navigation Examples

## Top Nav (Desktop)

```text
[Logo]    [Home] [Products] [Pricing] [Docs]    [Sign In] [Sign Up]
```

Active state: underline + accent color.

## Sidebar (Desktop)

```text
+----------+-----------------------------+
| Section 1| Main Content                |
| Section 2|                             |
| Section 3|                             |
| -------- |                             |
| Section 4|                             |
| Section 5|                             |
+----------+-----------------------------+
```

## Bottom Tab Bar (Mobile)

```text
+----------------------------------------+
| [Home] [Search] [+] [Alerts] [Profile]|
+----------------------------------------+
```
